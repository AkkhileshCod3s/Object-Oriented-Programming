A comprehensive repository containing Java-based solutions and standard practice problems covering core Object-Oriented Programming (OOP) concepts. Designed specifically to aid in mastering OOP fundamentals and preparing for university examinations, technical assessments.

---

## 📚 Topics Covered

* **OOP Pillars**
  ![OOP Pillars](https://img.shields.io/badge/OOP_Pillars-Abstraction_%7C_Encapsulation_%7C_Inheritance_%7C_Polymorphism-blue?style=flat-square)
  * Abstraction, Encapsulation, Inheritance (Single, Multilevel, Hierarchical), and Polymorphism (Overloading & Overriding).

* **Core Java**
  ![Core Java](https://img.shields.io/badge/Core_Java-Classes_%7C_Objects_%7C_Constructors_%7C_Keywords-orange?style=flat-square)
  * Classes, Objects, Constructors, `this` and `super` keywords, `static` members, and `final` keyword.

* **Abstract Classes & Interfaces**
  ![Interfaces](https://img.shields.io/badge/Abstraction-Abstract_Classes_%7C_Interfaces-red?style=flat-square)
  * Implementing abstraction, interface inheritance, and multiple inheritance via interfaces.

* **Exception Handling**
  ![Exception Handling](https://img.shields.io/badge/Errors-Exception_Handling-yellow?style=flat-square)
  * `try-catch` blocks, `finally`, custom exceptions, `throw`, and `throws`.

* **Collections & Generics**
  ![Collections](https://img.shields.io/badge/Data_Structures-Collections_%26_Generics-purple?style=flat-square)
  * Arrays, ArrayLists, HashMaps, and underlying data structure operations.

* **File Handling**
  ![File I/O](https://img.shields.io/badge/I%2FO-File_Handling-lightgrey?style=flat-square)
  * Reader/Writer classes, Scanner, and stream-based I/O operations.
